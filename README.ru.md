# LanWorlds

![LanWorlds](docs/lanworlds-cover.png)

[English](README.md) · [简体中文](README.zh-CN.md) · [Tiếng Việt](README.vi.md) · **Русский** · [Українська](README.uk.md) · [日本語](README.ja.md)

LanWorlds — клиентский мод Fabric, который улучшает стандартный список локальных игр Minecraft. Поддерживаются версии Minecraft **26.3, 26.2, 1.21.11 и 1.21.1**. Установите Fabric API и скачайте JAR для своей версии игры на странице [релизов GitHub](https://github.com/block-fox/LanWorlds/releases).

## Возможности

- Подключайтесь к комнатам из стандартного меню сетевой игры. Щёлкните по комнате правой кнопкой мыши, чтобы увидеть значок, объявления MOTD, MOTD сервера, адрес, число игроков и задержку, если эти данные доступны.
- Блокируйте комнаты по IP, по IP и порту или по объявленному MOTD. Можно выбрать и заблокировать несколько комнат сразу. Во вкладке заблокированных комнат можно удалить сразу несколько правил, даже если комнаты сейчас недоступны.
- Настраивайте запросы состояния комнат, время ожидания, правило блокировки по умолчанию, внешний вид и расположение кнопок. В режиме отображения только значков можно включить перетаскивание и перемещать их левой кнопкой мыши. Настройки хранятся в `config/lanworlds.json`.

## Папки комнат и поиск

Откройте меню **…** на экране сетевой игры, чтобы включить группировку, выбрать способ группировки, выполнить поиск или перейти к множественному выбору. Комнаты можно группировать по типу сети (Radmin или обычная LAN), IP, порту или MOTD. Щёлкните по заголовку папки, чтобы свернуть или развернуть её. В режиме множественного выбора флажок папки позволяет выбрать или снять выделение со всех её комнат, в том числе свёрнутых.

Ищите комнаты по IP, порту, MOTD или имени пользователя Radmin. Подсказки появляются над полем поиска или под ним, в зависимости от направления раскрытия меню. Выберите подсказку, чтобы перейти к комнате, сохранив состав основного списка.

Щелчок с Ctrl включает множественный выбор. Обычный щелчок переключает выделение, Shift позволяет выделить диапазон, а Ctrl+Shift — добавить диапазон. Ctrl+A выделяет все комнаты. На панели инструментов также можно выделить всё, инвертировать или сбросить выделение. Первое нажатие Esc сбрасывает выделение, второе завершает режим. После обновления выделение восстанавливается по адресу и порту. Подключение к комнатам приостанавливается на время множественного выбора.

## Необязательная интеграция с Radmin

LanWorlds работает самостоятельно с Fabric API. Если установить Radmin Linker 1.0.1 для той же версии Minecraft, у комнат с соответствующим виртуальным IP Radmin появятся сведения о пользователе, сети и соединении. Из сведений о комнате также можно открыть свойства пользователя и сети Radmin. Кнопка с синим щитом использует настройки внешнего вида и положения из LanWorlds. [Radmin Linker](https://github.com/block-fox/radmin-linker)

В RadminLAN 0.2.x встроена старая функция локальных комнат, поэтому эта версия несовместима с LanWorlds. Если `config/lanworlds.json` отсутствует, LanWorlds может перенести настройки запросов и правила блокировки из `config/radminlan.json`. Исходный файл сохраняется.

## Разработка

Minecraft 26.2 и 26.3 используют общий исходный код в корне проекта и JDK 25. Отдельные проекты для 1.21.11 и 1.21.1 используют JDK 21. Запускайте клиент разработки скриптом для нужной версии.

```powershell
./scripts/run-26.3.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-26.2.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-1.21.11.ps1 -JavaHome '<JDK 21 path>' -Online
./scripts/run-1.21.1.ps1 -JavaHome '<JDK 21 path>' -Online
```

Для сборки используйте соответствующий скрипт `scripts/build-*.ps1`. Результаты находятся в `versions/<minecraft-version>/build/`. Перед сборкой или сменой версии закройте клиент разработки. Если зависимости есть в кэше, можно опустить `-Online`. Обычная копия репозитория использует общедоступные зависимости Maven.

Регрессионные проверки охватывают перенос настроек, необязательную интеграцию, выбор комнат, пакетную блокировку и восстановление. Для 26.2 передайте свойства из `versions/26.2/gradle.properties` как аргументы `-P`. [Документация по интеграции на китайском](docs/radmin-integration.md)

```powershell
./gradlew.bat -I tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.11 -I ../../tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.1 -I ../../tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
```

Проверки Mixin загружают список сетевой игры и записи LAN в клиенте разработки. На 1.21.1 проверяются также сведения по правому щелчку, множественный выбор, обновление и пакетная блокировка. Тестовые настройки находятся в `.tmp/mixin-smoke-runtime/`.

```powershell
./gradlew.bat -I tests/mixin-smoke.init.gradle runClient --no-configuration-cache
./gradlew.bat -p versions/1.21.11 -I ../../tests/mixin-smoke.init.gradle runClient --no-configuration-cache
./gradlew.bat -p versions/1.21.1 -I ../../tests/mixin-smoke.init.gradle runClient --no-configuration-cache
```

## Происхождение и лицензия

LanWorlds вырос из функции локальных комнат RadminLAN 0.2.0, который теперь называется Radmin Linker. Мод поддерживается отдельно под исходной лицензией MIT. [Лицензия](LICENSE)
