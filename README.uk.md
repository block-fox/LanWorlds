# LanWorlds

![LanWorlds](docs/lanworlds-cover.png)

[English](README.md) · [简体中文](README.zh-CN.md) · [Tiếng Việt](README.vi.md) · [Русский](README.ru.md) · **Українська** · [日本語](README.ja.md)

LanWorlds — клієнтський мод Fabric, що покращує стандартний список локальних ігор Minecraft. Підтримуються версії Minecraft **26.3, 26.2, 1.21.11 і 1.21.1**. Встановіть Fabric API та завантажте JAR для своєї версії гри зі сторінки [випусків GitHub](https://github.com/block-fox/LanWorlds/releases).

## Можливості

- Приєднуйтеся до кімнат зі стандартного меню мережевої гри. Натисніть кімнату правою кнопкою миші, щоб побачити піктограму, MOTD оголошення та сервера, адресу, кількість гравців і затримку, якщо ці дані доступні.
- Блокуйте кімнати за IP, за IP та портом або за MOTD оголошення. Можна вибрати й заблокувати кілька кімнат одразу. На вкладці заблокованих кімнат можна видалити кілька правил одночасно, навіть якщо кімнати зараз недоступні.
- Налаштовуйте запити стану кімнат, час очікування, типове правило блокування, вигляд і розташування кнопок. У режимі лише піктограм можна ввімкнути перетягування й розміщувати їх лівою кнопкою миші. Налаштування зберігаються в `config/lanworlds.json`.

## Папки кімнат і пошук

Відкрийте меню **…** на екрані мережевої гри, щоб увімкнути групування, вибрати його спосіб, виконати пошук або вибрати кілька кімнат. Кімнати можна групувати за типом мережі (Radmin або звичайна LAN), IP, портом чи MOTD. Натисніть заголовок папки, щоб згорнути або розгорнути її. У режимі множинного вибору прапорець папки дає змогу вибрати або скасувати вибір усіх її кімнат, навіть згорнутих.

Шукайте за IP, портом, MOTD або іменем користувача Radmin. Підказки з’являються над полем пошуку або під ним, залежно від напрямку розгортання меню. Виберіть підказку, щоб перейти до кімнати зі збереженням основного списку.

Натискання з Ctrl вмикає множинний вибір. Звичайне натискання перемикає вибір, Shift виділяє діапазон, а Ctrl+Shift додає діапазон. Ctrl+A вибирає всі кімнати. Панель інструментів також дає змогу вибрати все, інвертувати або скинути вибір. Перше натискання Esc скидає вибір, друге завершує режим. Після оновлення вибір відновлюється за адресою й портом. Приєднання до кімнат призупиняється в режимі множинного вибору.

## Необов’язкова інтеграція з Radmin

LanWorlds працює самостійно з Fabric API. Якщо встановити Radmin Linker 1.0.1 для тієї самої версії Minecraft, у кімнатах з відповідною віртуальною IP-адресою Radmin з’являться дані про користувача, мережу й з’єднання. З відомостей про кімнату можна відкрити властивості користувача й мережі Radmin. Кнопка із синім щитом використовує налаштування вигляду та положення з LanWorlds. [Radmin Linker](https://github.com/block-fox/radmin-linker)

У RadminLAN 0.2.x вбудовано застарілу функцію локальних кімнат, тому ця версія несумісна з LanWorlds. Якщо `config/lanworlds.json` відсутній, LanWorlds може перенести налаштування запитів і правила блокування з `config/radminlan.json`. Початковий файл зберігається.

## Розробка

Minecraft 26.2 і 26.3 використовують спільний вихідний код у корені проєкту та JDK 25. Окремі проєкти для 1.21.11 і 1.21.1 використовують JDK 21. Запускайте клієнт розробки скриптом для потрібної версії.

```powershell
./scripts/run-26.3.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-26.2.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-1.21.11.ps1 -JavaHome '<JDK 21 path>' -Online
./scripts/run-1.21.1.ps1 -JavaHome '<JDK 21 path>' -Online
```

Для збирання використовуйте відповідний `scripts/build-*.ps1`. Результати збирання містяться в `versions/<minecraft-version>/build/`. Перед збиранням або зміною версії закрийте клієнт розробки. Якщо залежності вже є в кеші, параметр `-Online` можна опустити. Звичайна копія репозиторію використовує загальнодоступні залежності Maven.

Регресійні перевірки охоплюють перенесення налаштувань, необов’язкову інтеграцію, вибір кімнат, пакетне блокування та відновлення. Для 26.2 передайте властивості з `versions/26.2/gradle.properties` як аргументи `-P`. [Документація з інтеграції китайською](docs/radmin-integration.md)

```powershell
./gradlew.bat -I tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.11 -I ../../tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.1 -I ../../tests/regression.init.gradle lanWorldsRegressionCheck --no-configuration-cache
```

Перевірки Mixin завантажують список мережевої гри й записи LAN у клієнті розробки. Для 1.21.1 вони також перевіряють відомості за натисканням правої кнопки, множинний вибір, оновлення та пакетне блокування. Тестові налаштування зберігаються в `.tmp/mixin-smoke-runtime/`.

```powershell
./gradlew.bat -I tests/mixin-smoke.init.gradle runClient --no-configuration-cache
./gradlew.bat -p versions/1.21.11 -I ../../tests/mixin-smoke.init.gradle runClient --no-configuration-cache
./gradlew.bat -p versions/1.21.1 -I ../../tests/mixin-smoke.init.gradle runClient --no-configuration-cache
```
